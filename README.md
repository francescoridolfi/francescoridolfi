## About me

I'm a **Senior Fullstack Developer** and IT Consultant based in Rome, Italy.

I design and build production-grade systems — from backend APIs and data pipelines to mobile apps and AI integrations.
Currently working with **Trackting SRL** on vehicle security infrastructure, including a Business Intelligence platform and an AI-powered backend system.
I also work as lead Flutter developer for **Arval**'s dealership network and contributed to the Android MVVM migration for **Alphabet Mobility Services**.

I also maintain open source libraries and tools on GitHub, mostly focused on the **Django** ecosystem.
